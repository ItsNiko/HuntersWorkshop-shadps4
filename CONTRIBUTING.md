# Contributing

Reproducible bug reports and verified compatibility research are welcome. Include the Workshop version, exact native-port version/hash, item or effect IDs, and steps to reproduce. Redact personal paths from log excerpts. Keep game files and saves private.

Before submitting code, run `dev/verify.ps1`. Changes to game memory layout, hooks or calling conventions also require an explicitly isolated live integration pass and a clear testing report. Keep compatibility checks strict and preserve existing port hooks. Contributions use GPL-3.0-or-later.
