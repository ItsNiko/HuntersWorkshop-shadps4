HUNTER'S WORKSHOP 0.2.0
Standalone item spawner and blood gem studio for Bloodborne native PC.

Supported: official visy 0.6.7 / 0.6.8, Bloodborne 1.09, Windows 10/11 x64,
and .NET Framework 4.8. Unknown executables are refused.

1. Extract the ZIP and run HuntersWorkshop.exe.
2. Launch Bloodborne normally. Load a living hunter in your own world.
3. Click Connect to Bloodborne and wait for Hunter ready.
4. Choose an item or build a gem, then grant it.
5. Let the game's save indicator finish before exiting.

Includes base game/DLC equipment, all Lost/Uncanny weapon variants,
chalice gem strengths, six effect slots, Caryll runes, recipes and favorites.
Launch separately; no Vortex, Cheat Engine, Python or catalog download needed.

The first grant for a loaded character creates a backup. For the strongest
recovery point, use Session & backups with the game closed.
Preferences, recipes, logs and backups: %LOCALAPPDATA%\HuntersWorkshop

Restore only with Bloodborne closed. Preserve current saves separately, then
copy the backup's savedata and/or savedata_party into the Source directory
recorded in manifest.json. The app does not restore saves automatically.

Custom gems may exceed natural drop rules. Unused content may be incomplete.
Guest grants are refused. Multi-PC synchronization is untested. If a command
is uncertain, restart and inspect inventory/storage before repeating it.
See TESTING.md for verification details.
